# Переаттестация

## Возможности
- Вход по никнейму или электронной почте и паролю.
- Профиль: изменение никнейма и почты, выход из аккаунта.
- Опциональный вход через Discord OAuth2.
- Три стандартные переаттестации, в каждой ровно 10 вопросов.
- Кнопка «Пройти» случайно выбирает одну из доступных переаттестаций.
- Редактор вопросов для куратора/администратора.
- Управление ролями и аккаунтами для администратора.

## Запуск
Требуется Node.js 18+ и PostgreSQL.
1. Установите зависимости: `npm install`.
2. Скопируйте `.env.example` в `.env`.
3. Укажите `DATABASE_URL` и случайный `SESSION_SECRET` длиной не менее 32 символов.
4. Укажите `BOOTSTRAP_ADMIN_USERNAME`, `BOOTSTRAP_ADMIN_EMAIL` и `BOOTSTRAP_ADMIN_PASSWORD`. Пароль должен быть не короче 10 символов.
5. Запустите `npm start`.

При первом старте, если в базе ещё нет администратора, сервер создаст его из `BOOTSTRAP_ADMIN_*`. Не коммитьте `.env` в Git и не отправляйте пароль в открытые чаты. Если администратор уже существует, переменные bootstrap не меняют его пароль или роль.

## Discord OAuth
1. Создайте приложение в Discord Developer Portal.
2. В OAuth2 добавьте Redirect URL, точно совпадающий с `DISCORD_REDIRECT_URI`, например `https://YOUR-DOMAIN/api/auth/discord/callback`.
3. Добавьте `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET` и `DISCORD_REDIRECT_URI` в окружение сервера.
4. Перезапустите приложение. Для Discord-входа требуется HTTPS в production.

## Примечания
- На реальном сервере используйте HTTPS и секреты окружения хостинга.
- Новые наборы переаттестаций нужно заполнить до 10 вопросов перед тем, как их можно будет пройти.
- Начальные вопросы — демонстрационные; замените их на утверждённые вопросы вашей команды.
